# 为什么要先有地图

ISP（Image Signal Processor）是相机从"感光"到"出图"之间那条看不见的流水线。做相机开发这些年，我最深的体会是：**孤立地懂某个模块没用，脑子里得有整条链路的地图**——黑电平为什么要先做？3A 统计为什么挂在 RAW 域？降噪为什么分三个域去做？这些问题的答案都藏在链路顺序里。

这篇是这个专栏的总纲，把整条链路拆成五个阶段。后面每一篇都从这里出发。

# 五个阶段

## 一、光进入系统之前（光学）

镜头决定了光的"初始质量"：焦距决定视角，光圈决定进光量和景深，镜片组决定像差和 MTF。多摄系统还要考虑焦段覆盖、切换策略和标定一致性。

> 关键词：焦距 / 光圈 / MTF / 多摄切换 / 标定

## 二、光变成电（传感器）

CMOS 传感器把光子变成电荷再变成数字信号。微透镜、彩色滤光片（CFA/Bayer 阵列）、光电二极管、读出电路——噪声也从这里开始混进来：散粒噪声、读出噪声、暗电流。

> 关键词：Bayer / 量子效率 / 读出噪声 / DOL HDR

## 三、从 RAW 到 RGB（ISP 管线主体）

这是 ISP 的核心行军路线，顺序大有讲究：

1. **黑电平校正**——先把"零点"对齐，后面一切数学才成立
2. **坏点校正**——别让孤立坏点污染后面的统计
3. **去马赛克**——Bayer 拜耳阵列插值成全彩 RGB
4. **白平衡 / 色彩校正矩阵（CCM）**——从传感器色彩空间映射到标准色彩空间
5. **Gamma / 色调映射**——线性域到感知域
6. **降噪**——空域、时域、RAW 域各有分工
7. **锐化与细节增强**

而 3A（AE/AWB/AF）的统计信息大多取自 RAW 域或 RGB 域的关键节点，统计窗口的位置直接决定算法上限。

## 四、从像素到体验（画质调教）

同一套 ISP，不同的参数就是不同的"味道"。IQ 调教是把算法能力翻译成用户感知：色彩偏好、肤色还原、夜景观感、锐度风格。实验室指标（信噪比、MTF50、色差）和主观体验之间的桥，就是调教流程。

> 关键词：色彩科学 / 风格化 / 实验室指标 / 主观评价

## 五、从算法到产品（平台与工程）

ISP 最终跑在芯片上：高通平台的 ISP 硬件管线 + Chromatix 调优工具链，自研 SoC 则是另一套设计哲学——自研的好处是管线可以为产品定制，代价是什么都要自己补。HAL 层和 CameraService 负责把这一切组织成可靠的相机产品。

> 关键词：Chromatix / 自研 SoC / Camera HAL / 帧同步
