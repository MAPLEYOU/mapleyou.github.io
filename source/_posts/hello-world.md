# 为什么要有这个博客

公众号「码尘飞扬社」偏内容输出, 讲究排版和传播; 这里则更随意一些——记录技术探索的草稿、踩过的坑、还没想清楚的问题。两边互补:

- **公众号**: 成型的文章、教程、观点
- **博客**: 技术笔记、实验记录、一些不够"成文"但值得留档的东西

# 这里会写什么

大概率围绕这几条线:

1. **ISP / 影像**: 高通 HAL、CameraService、画质调教, 以及随之而来的多摄、标定、时序同步等话题
2. **系统底层**: Android Framework、Binder 通信、HIDL/AIDL 演进
3. **折腾记录**: 自建服务、自动化流水线、知识库工程

# 技术栈备忘

这个站本身也是折腾的一部分:

- **Hexo** 生成静态页面
- **Butterfly** 主题
- **GitHub Pages** 免费托管, GitHub Actions 自动构建部署
- 全部内容 Markdown 写作, 进 Git 仓库版本管理

写完 Markdown 推送到 GitHub, 剩下的交给 CI——这就是静态博客最舒服的地方: 内容在自己手里, 托管不花钱, 想搬去哪儿随时能搬。
