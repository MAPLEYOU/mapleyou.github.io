## 踩坑记录（重要，复用价值高）

1. **手写 Hexo package.json 必须带 `"hexo": {"version": "x.x.x"}` 字段**——hexo-cli 的 `find_pkg.js` 靠这个字段判断是否为 Hexo 站点，缺了就 fallback 全局模式（只显示 help/init/version，`generate` 不执行）。症状极具迷惑性，`hexo version` 正常但 `hexo generate` 打印帮助。
2. **Windows Git Bash 下 npx.cmd/npm.cmd wrapper 传参不可靠**（`npx hexo generate` 变成打印帮助），直接 `node node_modules/hexo/bin/hexo <cmd>` 稳定。
3. **YAML front-matter 的 title 含冒号必须加引号**（`title: "你好, 世界: xx"`），否则 js-yaml 报 bad indentation 且不生成该文章。
4. 本地预览: `node node_modules/hexo/bin/hexo server -p 4000`。
